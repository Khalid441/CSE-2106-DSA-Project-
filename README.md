# CSE-2106-DSA-Project-
Console-based e-commerce system in C++ demonstrating 12 core DSA concepts - arrays, linked lists, stacks, queues, sorting, BST, heaps, Fenwick tree, and graphs - implemented from scratch without STL containers.
To run this file create a folder in VS Code then paste the main cpp there,inside that folder create a new folder for the header files,then run the main.cpp
